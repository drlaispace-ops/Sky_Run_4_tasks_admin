# Tier-D: шахівниця, ліс і чесний оракул

**AI SkyRun · Tier-D · Звіт про дослідження · 15.07.2026**
*(markdown-копія Артефакту; ілюстрації — файли в цій самій теці `tier_d/reports/`)*

Базовий 2D-трек: як табличний Q-learning без нейромереж і без мапи вчиться
долітати з A до B за 94% від оптимуму, чому класичні потенціальні поля
програють йому на третині лісів, і скільки коштує стійкість до вітру.

**Коротко:** 125 тестів зелені · 100% успіху на прихованих сідах · η = 0.94
від оптимуму A* · 34% лісів ловлять APF у пастку · 0.2 с на 3000 епізодів.

---

## 1. Звідки взялася задача

Це фундамент проєкту — **змагальний трек хакатону**. Кіт організатора має
розв'язати чотири задачі одразу: ① однаковий світ для всіх команд
(біт-у-біт відтворюваний ліс); ② непідкупний суддя (ідеальний розв'язок для
порівняння); ③ видиме RL (графіки, поверхня цінностей, анімації);
④ простота: чистий Python + NumPy, без нейромереж і GPU.

> **Словничок.** *MDP* — модель світу для RL: стани, дії, переходи,
> винагороди. *Q-learning* — навчання таблиці Q(стан, дія) за правилом
> `Q ← Q + α·(r + γ·max Q′ − Q)`. *ε-greedy* — з імовірністю ε випадкова
> дія (розвідка), інакше найкраща відома (використання).

## 2. Постановка: світ як шахівниця

Домен 10×10 м → сітка **25×25** (крок 0.4 м). Старт A(1,1), ціль B(9,9).
Стан агента — **лише номер клітинки** (1 з 625). Дії — 8 напрямків без
зрізання кутів. Винагороди: −1 крок, −100 колізія (термінал), +100 ціль
(термінал), γ = 0.99.

> **Інваріант №2 — серце треку.** Агент ніколи не бачить дерев — лише номер
> клітинки і пережитий досвід. Гвард `BlindEnv` кидає виняток на будь-яку
> спробу підглянути мапу.

Суддя — **A\*** («оракул») з повною мапою рахує оптимум L*. Оцінка:
`efficiency = L*/L ≤ 1`.

## 3. Математика: п'ять законів

| Закон | Зміст |
|---|---|
| `mulberry32(seed) → ліс` | 32-бітний PRNG, портований з JS біт-у-біт: однаковий ліс у Python і в браузері; golden-тест в обох мовах |
| `F = γ·Φ(s′) − Φ(s), Φ(терм)=0` | shaping за Нг–Харадою–Расселом не змінює оптимум; перевірено: Σ F по циклу = 0, shaped/plain сходяться до одного L* |
| один `TREE_R` на всіх | радіус колізії в одному файлі, env і оракул імпортують його; інакше η може перевищити 1 і лідерборд бреше |
| `−1/(1−γ) = −100` | вічне блукання коштує рівно як колізія; «суїцид» ледь-ледь нераціональний, мету рятує +100 |
| `TREE_R = CELL, SEP = 0.85` | генератор фізично не може скласти суцільну стіну — жоден сід не буває непрохідним |

## 5. Хід роботи: вісім фаз

Фази суворо послідовні (gate-дисципліна, успадкована потім Tier-A/B):

1. **Інструменти + RNG** — ключове рішення: mulberry32 з JS замість numpy,
   щоб браузер і Python бачили один ліс без синхронізації.
2. **Світ** — rejection sampling з 3 обмеженнями; BlindEnv-гвард стану.
3. **Оракул** — A* по тій самій зайнятості (інваріант 3); string_pull —
   лише для малюнків, скоринг по ньому зробив би η=1 недосяжною.
4. **Q-learning + shaping** — Φ(термінал)=0 обов'язково, інакше гарантія
   ламається на терміналі колізії; shaped і plain сходяться рівно до L*.
5. **Візуалізація** — піки над деревами лише з пережитих зіткнень
   (Q(сусід, дія-в-дерево)), незаймані дерева плоскі.
6. **Скоринг** — greedy-оцінка (не exploration), право-цензурування
   бюджетом, приховані сіди ніколи не в тренуванні.
7. **Скаффолд** — ноутбук з двома TODO, методичка, самоперевірка.
8. **Webots-міст (частково) + пакування (не почато)** — міст юніт-тестований
   (118 тіків до цілі), симулятор не встановлено; версії не заморожені.

## 6. Результати

### Лідерборд (приховані сіди, бюджет 3000 епізодів)

| Агент | Success | Колізії | L*/L | Епізодів до 1.15·L* |
|---|---|---|---|---|
| reference (Q + shaping) | **1.00** | 0.00 | **0.937** | **1990** (90%) |
| ablation (без shaping) | 1.00 | 0.00 | 0.916 | 2492 (80%) |
| baseline (випадковий) | 0.00 | 0.00 | 0.000 | 3000 (0%) |

Теорема наживо: shaping не покращив збіжну політику, але дав ~20% швидшу
збіжність. Публічні сіди: reference η=0.945, 1781 еп.

## 8. Глибокий аналіз

### Що правильно

| Рішення | Чому |
|---|---|
| 6 інваріантів як тести | кожне «не можна» закодовано перевіркою; без них кіт «працює, оцінює і бреше» |
| mulberry32 замість numpy | один PRNG на дві мови, golden-тест; дешевше за синхронізацію двох генераторів |
| APF як контрольований фол | гейни з sweep по 120 лісах — 34% пасток це чесний аргумент, не підтасовка |
| Право-цензурування | один недольот = ∞ у середньому; цензурування бюджетом рятує метрику |
| Greedy-оцінка | з ε=0.05 агент «гуляє» вічно — навчання видно лише без розвідки |
| string_pull лише для ока | межа «красиво/чесно» проведена явно |
| Піки цінності з пережитого | поверхня зобов'язана навчанню, а не дизайнеру |

### Що не так (або далося дорого)

| Проблема | Чесна оцінка |
|---|---|
| HIDDEN_SEEDS у репо | перед подією винести з роздаваного коду — ручний крок, легко забути |
| Фаза 7 не end-to-end | Webots не встановлено; міст ніколи не крутив справжній симулятор |
| Фаза 8 не почата | без version freeze і дзеркала pip день-1 залежить від Wi-Fi |
| Скрипти експериментів поза тестами | баг History жив непоміченим; ядро покрите, integration — ні |
| Q-рядок цілі | термінал не оновлюється, argmax дає «дію 0» — вже вкусило webots-міст |
| Баланс −1/(1−γ)=−100 | тримається на точних константах; захищений документацією, не тестом |

### Чи це об'єктивно найкраще рішення?

**Для своєї мети — так.** На 625 станах табличний Q-learning — адекватний
інструмент, а не спрощення: сходиться за 0.2 с, прозорий, його межі
показуються експериментом. Нейромережа дала б те саме повільніше й
непрозоріше. Межі відомі й виміряні: світ-телепорт не знає про політ
(→ Tier-A), а безнавчальні альтернативи (APF) програють на 34% лісів.
Кіт — не роботика; він **чесна лабораторія RL**, і критерії чесності в
ньому виконуються машинно.

## 9. Що вдосконалювати

- **Винести HIDDEN_SEEDS** + тест, що роздаваний пакет їх не містить.
- **Integration-smoke кожного entry-point** у CI (урок бага History).

- **Фаза 8**: pip freeze після сухого прогону + локальне дзеркало.
- **Тест балансу констант** −1/(1−γ) = |R_COLLISION|.
- **20+ сідів у вітряній серії** з довірчими інтервалами.

## 10. Підсумок

Tier-D — єдиний трек, який повністю переміг свою задачу: 100% успіху,
94% оптимальності, нуль колізій, кожне «чесно» — під тестом. Він дав
проєкту відтворюваний світ, непідкупного суддю і культуру вимірюваних
тверджень — а ще чесно назвав власну межу («клітинки не літають»), з якої
виросли Tier-A (фізичне вето фіксованої тяги) і Tier-B (пірует виконано
SAC-ом). Уся драбина проєкту стоїть на цій шахівниці.
