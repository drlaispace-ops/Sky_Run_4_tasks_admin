## Типові проблеми на дні подієї

### 1. Агент не вчиться (крива = нулі)

**Є 5 причин:**

| Симптом | Перевірка | Рішення |
|---|---|---|
| Жадібна політика ніколи не дійшла | Чи мають значення в лист `curve`? | Підніміть `EPS0 = 0.5` або `EPISODES = 5000` |
| Шуміла крива, але середня = 0 | Чи `terminal` флаг правильно? | Переглядайте `info["collision"]` vs `info["goal"]` |
| Всі значення `Q[s, a]` = 0 | Чи виконується `q_update`? | Додайте `print(td)` для дебагу |
| TODO 1 не заповнено | Чи є `target = ...` ? | Скажіть команді знайти і заповнити |
| Φ(terminal) ≠ 0 | Чи умова `if terminal` в shaping? | Виправляйте: `phi_next = 0.0 if terminal else potential(s2)` |

**Швидка діагностика:** попросіть учня додати `print` кожні 100 епізодів, щоб бачити `Q[start_cell]` росте чи ні.

### 2. Крива піднялась, але plateau-ер

**Причини:** ε спадає занадто швидко, агент рано «застигає» на локальному оптимумі.

**Рішення:** 
```python
# Замість:
EPS_decay_frac = 0.6    # ε падає на 60% шляху

# Спробуйте:
EPS_decay_frac = 0.8    # ε падає на 80% шляху
```

Чим пізніше ε впирається в 0.05, тим більше дослідження, тим краще коли-то зміщувати оптимум.

### 3. L дуже велике, хочаSuccess = True

**Причини:** агент дійшов, але шлях дуже крученої.

**Рішення:**
- Збільште EPISODES (агенту просто потрібно більше часу)
- Зменште ALPHA на 2× (Q стрибає, не збігається)
- Спробуйте curriculum (почніть близько до цілі)

### 4. Колізії під час greedy rollout

Це **неможливо** у базовому `env.step()`: якщо дія ведить у дерево, агент стає в попередній клітинці (не рухається). Це не баг, це функція.

Однак якщо `info["collision"] = True`, значить агент вдарився, і це рахується як **collision** на табло.

## Трохи мотивації

**Чому трек APF не рекомендується?** (якщо хтось запитає)

APF чита-читає координати дерев з середовища. Це робить порівняння несправедливим:
- APF: знає карту, планує A* шляхом, але застрягає в локальних мінімумах
- RL: не знає карти, але _вчиться_ з досвіду, тому долає локальні мінімуми

Якщо дозволити обом командам читати дерева, RL майже завжди програє (більше обчислень, більше часу). Тому забрали дерева й дали RL справедливу гру.
