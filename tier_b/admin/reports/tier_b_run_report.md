# Tier-B: звіт про повний прогін (2026-07-15)

Прогін треку CTBR Pirouette у conda-середовищі `drones`. Тренування (2×2M
кроків, години) не повторювалося — воно відтворюване скриптами; прогін
перевіряє тести, детерміновану оцінку **навчених** моделей на held-out сідах
і регенерацію порівняння.

```bash
~/miniconda3/envs/drones/bin/python -m pytest tier_b/tests
```
